# Customer Shopping Behavior Analysis

## Project Overview
This project focuses on analyzing customer shopping behavior to understand purchasing patterns, customer preferences, spending habits, and shopping trends.

The analysis uses Python, SQL, and Power BI to extract meaningful insights from customer shopping data and support data-driven business decisions.

## Objectives
- Analyze customer purchasing behavior and shopping patterns.
- Identify popular product categories and frequently purchased items.
- Understand the relationship between customer demographics and spending.
- Evaluate the impact of discounts and promotional offers.
- Analyze customer subscription status and shopping frequency.
- Build an interactive dashboard to monitor key business metrics.

## Tools & Technologies
- **Python:** Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** Data querying, aggregation, filtering, and business analysis
- **Power BI:** Interactive Dashboard and KPI Visualization
- **Jupyter Notebook:** Python analysis

## Dataset Description
The dataset contains customer shopping information, including:

- Customer ID, Age, Gender
- Item Purchased and Product Category
- Purchase Amount
- Location and Season
- Review Rating
- Subscription Status
- Shipping Type
- Discount and Promo Code Usage
- Previous Purchases
- Purchase Frequency

## Project Workflow

### 1. Data Cleaning & Preparation
- Loaded the dataset using Python.
- Checked missing values and duplicate records.
- Examined data types and statistical summaries.
- Prepared the data for analysis.

### 2. Exploratory Data Analysis (Python)
Performed data analysis and visualizations to identify:
- Customer distribution by gender and age.
- Popular product categories and items.
- Seasonal shopping trends.
- Customer spending patterns.
- Discount and promotional code usage.
- Customer ratings and preferences.

### 3. SQL Analysis
Used SQL queries to:
- Analyze customer purchasing patterns.
- Calculate revenue and average purchase amounts.
- Identify popular product categories.
- Compare customer spending behavior.
- Analyze subscription and discount usage.

### 4. Power BI Dashboard
Created an interactive dashboard to visualize:
- Total Customers
- Total Revenue
- Average Purchase Amount
- Average Review Rating
- Subscription Rate
- Discount Usage Rate

## Business Insights
The analysis aims to identify:
- Customer segments with different purchasing behaviors.
- Product categories generating higher revenue.
- Seasonal shopping preferences.
- The relationship between discounts and purchase amounts.
- Differences in spending between subscribed and non-subscribed customers.
